```
本物の港区に生えてくる六本木ヒルズを、上スワイプで引っこ抜け！東京タワーや富士山も見える3Dカジュアルゲーム。
```

**詳しい説明**

```
港区のあちこちから、六本木ヒルズが筍のようにニョキニョキ生えてきた！
上にスワイプして、根っこごと引っこ抜け。ドスンと倒れて、土煙が舞い上がる。
早く見つけるほど楽に抜けて高得点。放っておくと根付いて、港区がヒルズだらけに……！

■ 本物の東京・港区が舞台
・国土交通省の3D都市モデル「PLATEAU」から作った、約10万棟の建物と道路を3Dで再現
・六本木ヒルズから半径5km。六本木、麻布、赤坂、虎ノ門、新橋、汐留、品川、渋谷、新宿まで
・東京タワー、東京スカイツリー、レインボーブリッジ、そして遠くに富士山も見える
・皇居や明治神宮など、東京の緑の中にもヒルズが生えてくる

■ 上スワイプで引っこ抜くだけの簡単操作
・ヒルズの近くで上にスワイプすると、ズボッと引っこ抜ける
・顔を出したばかりの「極上の朝掘り」は500点。育つほど長いスワイプが必要になる
・抜いたヒルズは宙を舞い、横倒しにドスン！土煙が広がる
・根付いたヒルズも、何回かスワイプすれば根っこごと抜ける

■ 地下鉄ごと引っこ抜け
・地下鉄の線路の近くに生えたヒルズは、根っこに電車が絡まっている
・電車ごと引っこ抜くとボーナス！

■ 街を見回して探す「ヒルズ狩り」
・左右のスワイプで向きを変え、2本指で前進、ピンチで拡大・縮小
・画面端の矢印とレーダーで、生えてきたヒルズの場所がわかる。タップでひとっ飛び
・根付いたヒルズが5本になると港区陥落。制限時間は90秒

■ その他
・「見習い筍掘り」から「港区の守護神」までのランク
・スコアとランクを友だちにシェア
・続けて抜くとコンボで点数アップ
・港区陥落のときは、広告を見て続けられる（1ゲーム1回）
・祭り囃子風のオリジナルBGMと効果音
・オフラインでも遊べる（広告・シェアは通信が必要）
・日本語・英語対応

ちょっとした暇つぶしに、東京の街でヒルズ狩りを。何本引っこ抜けるかな？

※本作は、森ビル株式会社および実在の施設・交通事業者とは関係のない、非公式のゲームです。
※建物・道路：国土交通省 Project PLATEAU 3D都市モデルを加工して作成
```
